# Support boundary

## Template maintainers support

- Railway build and startup behavior
- The authenticated adapter and `/healthz`
- Generated-variable contract
- `/data` mount and UID/GID 1500 initialization
- Documentation and reproducible package tests
- Bugs caused by the wrapper or template configuration

## Upstream or user-owned

- InfluxDB query language, schema design, ingestion clients, plugins, and
  upstream database defects
- Capacity planning, production architecture, HA, replication, and clustering
- User networking, custom domains, client code, dashboards, and integrations
- Operator execution and retention of backups
- Railway account, billing, quota, region, and platform incidents

Use the repository bug-report form for template issues. Remove secrets and
sanitize logs. Security issues belong in a private advisory, not a public issue.
